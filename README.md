# TestClick

## Summary
TestClick is a API prototype Programmatic Digital Out-of-home (PDOOH) advertisement management system.

<hr>

## APIS

**Screen**

- `GET /Dropdown/GetDropdown/Player`
- `GET /Screen/GetScreen`
- `POST /Screen/ScreenIns`
- `PUT /Screen/ScreenUpd`
- `DELETE /Screen/ScreenDel`
- `POST /Screen/ScreenIns/Tsk`
